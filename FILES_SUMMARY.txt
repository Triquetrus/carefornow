📊 PIPELINE FLOW
────────────────

1. PATIENT REGISTRATION & SETUP
   └─ Register → Set Bank Details

2. CASE CREATION
   └─ Fill Multi-Step Form

3. DOCUMENT UPLOAD
   └─ Upload Aadhar, Hospital Letter, Cost Estimate, etc.
   └─ Status: documents_pending

4. HOSPITAL VERIFICATION
   └─ Hospital Reviews Documents
   └─ Verifies Each Document
   └─ Status: verified (when all approved)

5. FUNDING APPLICATION
   └─ System Matches Best Funders
   └─ Patient Applies to Funders
   └─ Status: verified (case awaiting funder decision)

6. FUNDER REVIEW & APPROVAL
   └─ Funder Sees Verified Documents
   └─ Funder Sees Patient Bank Details
   └─ Funder Approves with Amount (e.g., ₹450K out of ₹500K requested)
   └─ Payment Record Created Automatically
   └─ Status: approved_for_funding

7. ADMIN PAYMENT RELEASE
   └─ Admin Sees Pending Payment
   └─ Admin Releases Payment
   └─ Status: funded
   └─ Case marked as complete

8. PATIENT RECEIVES FUNDS
   └─ Funds transferred to patient's bank account
   └─ Payment shows as "Released"
   └─ Patient can see in /my-funding
