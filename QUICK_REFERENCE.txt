## 🏃 RUN LOCALLY (5 MINUTES)

```bash
# 1. Setup
cd carefor-now
python3 -m venv venv
source venv/bin/activate          # macOS/Linux
# or: venv\Scripts\activate       # Windows
pip install -r requirements.txt

# 2. Configure
cp .env.example .env
# Edit .env with your database URL

# 3. Database
python3 << 'EOF'
from app import app, db
with app.app_context():
    db.create_all()
    print("✅ Database ready!")
EOF

# 4. Run
python app.py

# 5. Test
# Open 4 browser windows: http://localhost:5000
# Follow testing guide in QUICK_START.md
```

## 🔐 IMPORTANT: Environment Variables

**NEVER commit .env file to GitHub!**

```bash
# .env should contain:
DATABASE_URL=postgresql://user:pass@localhost/carefor_now
FLASK_ENV=production
SECRET_KEY=super-secret-key-here
UPLOAD_FOLDER=uploads
MAX_CONTENT_LENGTH=52428800

# Add to .gitignore:
.env
*.env
.env.*
```

**On Deployment:**
```bash
# Heroku
heroku config:set DATABASE_URL=postgresql://...
heroku config:set SECRET_KEY=your-key

# DigitalOcean (edit .env on server)
ssh root@your-ip
nano /path/to/app/.env
```

## 📊 DATABASE SETUP

### PostgreSQL
```bash
# Create database
createdb carefor_now

# Create user
createuser carefor_user -P

# Grant permissions
psql
GRANT ALL PRIVILEGES ON DATABASE carefor_now TO carefor_user;
\q

# Connection string for .env:
DATABASE_URL=postgresql://carefor_user:password@localhost/carefor_now
```

### SQLite (Local Dev Only)
```bash
# Just set in .env:
DATABASE_URL=sqlite:///carefor_now.db

# Database file created automatically
```

## 🐛 TROUBLESHOOTING

**Q: "Module not found: flask"**
```bash
source venv/bin/activate
pip install -r requirements.txt
```

**Q: "Database error"**
```bash
python3 << 'EOF'
from app import app, db
with app.app_context():
    db.create_all()
EOF
```

**Q: "Port 5000 already in use"**
```bash
python app.py -p 8000
# Or kill the process
lsof -i :5000
kill -9 <PID>
```

**Q: "Permission denied pushing to GitHub"**
```bash
# Use SSH key instead of HTTPS
git remote set-url origin git@github.com:YOUR-USERNAME/carefor-now.git
git push
```

**Q: ".env not being ignored"**
```bash
git rm --cached .env
echo ".env" >> .gitignore
git commit -m "Remove .env from tracking"
git push
```
