🧪 QUICK TESTING GUIDE
══════════════════════

Open 4 browser windows with different roles:

Window 1: Patient
  1. Register as "family" user
  2. Set bank details at /profile
  3. Create case at /new-case
  4. Upload documents at /case/{id}
  5. View status at /track-status/{id}

Window 2: Hospital
  1. Register as "hospital" user
  2. Go to /hospital-dashboard
  3. Review patient's documents
  4. Verify each document
  5. Case becomes "verified"

Window 3: Funder
  1. Register as "funder" user
  2. Go to /funder-dashboard
  3. Review patient's case
  4. See verified documents
  5. Approve with amount (e.g., ₹450K)

Window 4: Admin
  1. Register as "admin" user
  2. Go to /admin-dashboard
  3. See pending payment
  4. Release payment
  5. Case becomes "funded"

Back to Window 1: Patient
  ✅ Case now shows as "Funded"
  ✅ Payment visible in /my-funding
  ✅ Complete pipeline in /track-status

📞 NEED HELP?
═════════════

Issue: "Tables don't exist"
→ Run: python3 -c "from app import app, db; app.app_context().push(); db.create_all()"

Issue: "File upload fails"
→ Create: mkdir -p uploads && chmod 755 uploads

Issue: "Can't see payment"
→ Check: Patient must have bank details + Funder must approve + Admin must release

Issue: "Hospital can't verify"
→ Check: Patient must upload documents first
